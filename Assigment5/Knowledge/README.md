# AI-Based Travel Planner using Knowledge Graphs

## Overview

This project implements an AI-Based Travel Planner using a Knowledge Graph approach with Neo4j.

The system stores and connects:
- Tourists
- Destinations
- Restaurants
- Hotels
- Travel Preferences
- Budget Information

Using graph relationships and Cypher queries, the planner generates personalized travel recommendations based on:
- Budget
- Food preferences
- Travel interests
- Hotel ratings

---

# Technologies Used

- Python
- Neo4j Graph Database
- Cypher Query Language
